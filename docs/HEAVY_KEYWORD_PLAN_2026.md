# Heavy Keyword Plan (2026)

## Goal
Win rankings for high-intent keywords across lyrics, quiz, and verse categories by matching each keyword cluster to a dedicated index page plus deep pages.

## Primary Clusters and Target URLs

### 1) Hindi Lyrics + Chords (Highest priority)
- Core keywords:
  - `hindi christian songs lyrics`
  - `yeshu ke geet lyrics`
  - `hindi worship songs chords`
  - `masih geet lyrics`
- Index URLs:
  - `/hindi-songs`
  - `/hindi-christian-songs-lyrics-chords`
- Deep URLs:
  - `/hindi-songs/:slug` (all songs)
- Execution:
  - Keep full Hindi lyrics in static HTML.
  - Add English meaning and chord blocks where available.
  - Add 6+ related-song links per song page.

### 2) Song-Specific Head Terms (Commercial intent)
- Core keywords:
  - `ho teri stuti aur aradhana lyrics`
  - `apna bojh prabhu par daal lyrics chords`
  - `hallelujah stuti gaye hum lyrics`
- URLs:
  - `/ho-teri-stuti-aur-aradhana-lyrics-telugu-kannada-malayalam`
  - `/apna-bojh-prabhu-par-daal-lyrics-chords`
  - `/hallelujah-stuti-gaye-hum-lyrics`
- Execution:
  - Ensure each page has full lyric text, chord pattern, FAQ, and internal links back to `/hindi-songs`.

### 3) Bible Quiz Heavy Terms
- Core keywords:
  - `bible quiz questions and answers`
  - `bible quiz for sunday school`
  - `free bible quiz no signup`
  - `old testament quiz`
  - `new testament quiz`
- URLs:
  - `/bible-quiz-questions-and-answers`
  - `/bible-quiz-for-sunday-school`
  - `/free-bible-quiz-no-signup`
  - `/old-testament-quiz`
  - `/new-testament-quiz`
- Execution:
  - Add rich FAQ schema + internal links to book/chapter quizzes.

### 4) Verse Topic Heavy Terms
- Core keywords:
  - `bible verses about strength`
  - `bible verses about love`
  - `bible verses about hope`
  - `bible verses about faith`
- URLs:
  - `/verses/strength`
  - `/verses/love`
  - `/verses/hope`
  - `/verses/faith`
- Execution:
  - Expand with contextual commentary and cross-links among verse pages.

## On-Page Rules (for all heavy keyword pages)
- Put exact primary keyword in:
  - Title
  - H1
  - First paragraph
  - Canonical URL slug
- Add 3-5 secondary variants naturally in headings and body.
- Include one FAQ block with question phrasing matching search intent.
- Keep 8-20 internal links per page (mix: parent hub, related pages, adjacent content).

## Technical Rules
- No thin placeholders on indexable URLs.
- Keep `robots` as `index,follow` on ranking targets.
- Ensure sitemap includes all ranking targets.
- Use breadcrumb schema on deep pages and `ItemList` schema on hub pages.

## 60-Day Rollout

### Week 1-2
- Stabilize Hindi song index + all Hindi detail pages with real static lyric content.
- Fix keyword hub pages and internal links.

### Week 3-4
- Expand top 30 song pages with:
  - full chords
  - line-level English meaning
  - short FAQ

### Week 5-6
- Build 20 long-tail supporting pages:
  - `"<song name> lyrics in hindi"`
  - `"<song name> chords"`
  - `"<song name> meaning"`

### Week 7-8
- Refresh titles/descriptions using Search Console query data.
- Increase internal links from high-impression pages to pages in positions 8-20.

## KPI Targets
- Hindi cluster:
  - 2x indexed pages with valid rich snippets.
  - Top 20 for 20+ song-specific terms.
- Quiz cluster:
  - Top 10 for at least 5 heavy quiz queries.
- Verses cluster:
  - Top 15 for 4 head verse terms.
