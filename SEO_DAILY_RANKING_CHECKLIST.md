## Daily Checklist
1. Check Google Search Console performance
- Compare last 7 days vs previous 7 days:
  - Total clicks
  - Total impressions
  - Average CTR
  - Average position
- Note top 10 queries by impressions.
- Mark queries with falling position or low CTR (<2%).

2. Check indexing health (Search Console)
- Page indexing: any new "Crawled - currently not indexed" URLs?
- Any "Duplicate, Google chose different canonical"?
- Any "Blocked by robots.txt" for pages that should rank?
- Request indexing for newly published SEO pages if needed.

3. Check canonical + host consistency
- Confirm canonical host is always `https://biblequizcompetition.com` (no `www` canonicals).
- Confirm `www.biblequizcompetition.com` permanently redirects to non-www.
- Check 2-3 random pages for canonical correctness.

4. Check sitemap freshness
- Ensure `public/sitemap.xml` contains new SEO pages.
- Ensure last generated date is recent after updates.
- Re-submit sitemap in Search Console if major new pages were added.

5. Check top landing pages performance
- Review these pages:
  - `/public-quiz`
  - `/bible-questions`
  - `/prayers`
  - `/free-bible-quiz-questions-and-answers`
  - `/bible-trivia-questions-and-answers`
  - `/bible-quiz-for-kids-teens-adults`
- Note if clicks/impressions are rising or flat.

6. SERP snapshot (manual)
- Search 3-5 core keywords in incognito.
- Record top competing domains seen repeatedly.
- Compare your title/meta snippets against top 3 results.

7. CTR improvement opportunities
- For pages with impressions but weak CTR:
  - Update title (benefit + intent + year/version if relevant)
  - Update meta description (clear promise + relevance)
- Keep one controlled change per page, then monitor for 7-14 days.

8. Content/internal-link action
- Add 1-2 internal links from strong pages to priority ranking pages.
- Ensure anchor text matches query intent naturally.
- Add one FAQ entry or short section to a target page if query gap is found.

9. Technical quality quick checks
- Mobile usability issues in Search Console
- Core Web Vitals trend (especially LCP and INP on key pages)
- No accidental `noindex` on pages meant to rank

10. Backlink growth (weekly quick check, daily note if any)
- Log any new mentions/links earned.
- Identify 1 outreach target (church site, youth ministry blog, Christian resource page).
